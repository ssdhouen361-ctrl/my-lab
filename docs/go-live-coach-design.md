## 1. システム概要と開発方針

### 1-1. コンセプト
「KataGoの冷徹な計算力を頭脳とし、Geminiが優しい人間の先生のように対話しながら盤面を実演する、リアルタイム囲碁検討パートナー」。
勝率や青い点を眺めるだけでなく、並べ替え・巻き戻し・部分的なワカレの評価を自然言語でリアルタイムに検討できます。

### 1-2. 前提環境とリポジトリ運用
- **Mac mini（M6 GPU / macOS）**:
  - KataGo v1.18.2（Metal GPU-only / Analysis Engineモード）
  - FastAPI + WebSocket（Python 3.12 / 127.0.0.1:8095 / `--workers 1`）
- **クライアント**:
  - Galaxy Tab S11（横画面 16:10 / 2560×1600）
  - Tailscale経由（HTTPS / WSS）によるPWAアクセス
- **リポジトリ規約**:
  - 運用中プロジェクト `web-goban` は完全コードフリーズを維持。
  - 新規プロジェクト `projects/go-live-coach/` として独立構築し、KataGo連携やルール計算の知見のみを安全に継承。

### 画面制御の重要技術要件（UI/UX審査結果）
1. **2層Canvas構成**:
   - **下層（メイン盤面）**: 確定石、星、目盛り。高DPR（`devicePixelRatio * 2`）および物理ピクセル半ピクセル補正（スナップ）で滲みゼロ。
   - **上層（ゴーストレイヤー）**: AIの変化手順（半透明の①②③）、部分検討の選択枠、ホバー照準。本譜ツリーを汚染せずに即座にクリア可能。
2. **Android仮想キーボード対策**:
   - `interactive-widget: overlays-content` / Flexレイアウトにより、ソフトウェアキーボード出現時も左側の盤面サイズを絶対に縮小・歪ませない（盤面保護）。
3. **Sペン ＆ タッチ分離**:
   - `pointerType === 'pen'` を検知した場合、手のひら誤爆（パームタッチ）を完全無視。ペン先ホバーで着手ガイドを表示。

## 4. コア機能詳細仕様

### 4-1. 発話スマート要約フィルター（Single-Pass 構造化出力）
ユーザーが音声で考えながら話した「あー…うーん…ノビてたら…いやツギか…」といった言い淀みや自己訂正を、LLMの1回のリクエスト（`response_schema`）で同時に処理します。

```json
{
  "user_intent_summary": "白のハネに対して黒がツギを選択した場合の局所変化について",
  "coach_reply": "ツギを選択した場合、白は先手を取って下辺へ展開する余地が生まれます。実戦のハネ出しと比べると…",
  "board_actions": [
    {"type": "show_candidates", "coords": ["D4", "C5", "D6"]},
    {"type": "play_variation", "moves": ["D4", "C5", "D6"], "label_step": true},
    {"type": "undo_moves", "count": 3}
  ]
}
```
- UI側のチャット欄には、整った `user_intent_summary` のみを記録するため、議事録のようにクリーンな履歴が保たれます。

### 4-2. 部分的なワカレの検討（局所評価スライスロジック）
- KataGoは全盤で推論させつつ、KataGoが返す `ownership`（盤上361箇所の領分確率 -1.0〜+1.0）から、ユーザーが選択した矩形領域（またはAIが特定した局所）のデータを抽出。
- **局所地合い**: 選択領域内の ownership 総和（目数換算）。
- **局所厚み・影響力**: 領域境界の石の呼吸点および領域外への policy（着手推奨度）分布からスコア化。
- これにより、盤全体の勝率だけでなく「左上のワカレは黒が+2.0目リード、かつ厚み有利」といった局所評価を言語化。

### 4-3. AIによる自律実演（並べ替え・巻き戻し）
Geminiが返した `board_actions` に基づき、上層Canvas（ゴーストレイヤー）で以下を実行：
1. **候補手マーカー**: 候補3手（A, B, C）を半透明で同時点灯。
2. **手順実演**: 1手ずつ約400ms間隔で番号付きゴースト石を打ち進める。
3. **自動巻き戻し**: 解説の区切りで自動的に手を戻し、別の変化手順を並べる。
4. **本譜採用**: チャット欄の「▶ 変化図を本譜に採用」ボタンを押すと、いつでもその変化を実譜ツリーへ昇格可能。

### 4-4. モデル柔軟切り替え ＆ APIコスト保護設計
- **モデル非依存（Future-Proof）**:
  `.env` の1行書き換えで即座に新モデルへ切り替え可能。
  ```bash
  COACH_PROVIDER=gemini-api
  COACH_MODEL=gemini-2.5-flash
  # 来月新モデル登場時は書き換えるだけ:
  # COACH_MODEL=gemini-3.5-flash
  ```
- **多重フォールバック（Circuit Breaker）**:
  Gemini API ➔ 失敗時: Mac mini内 `agy CLI` ➔ 非常時: 定型ルールベース解説（`RuleBasedFallbackCoach`）。
- **コスト・トークン安全設計**:
  - 直近3〜4ターンの会話のみを送信し、古い会話は100字程度に要約圧縮（トークン爆発防止）。
  - **設定画面（右上の歯車）**内に「本日の利用推定額」「累計消費トークン」を静かに表示。メイン検討画面は邪魔しない。
