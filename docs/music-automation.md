# Galaxyアラーム連動 Apple Music自動再生システム 設計・手順書

Galaxy S26 Ultraのアラーム鳴動をトリガーにして、Discord経由でMac miniのApple Music（指定プレイリスト）を自動再生するプロジェクトの設計書および構築手順です。

---

## 1. システム全体像（アーキテクチャ）

スマホとMacを直接通信させるにはネットワーク設定（ポート開放など）が複雑になるため、**Discordを中継所（ハブ）として使う**ことで、安全かつ簡単に連携させます。

```
[Galaxy S26 Ultra]
  │ ① アラームが鳴る（モードとルーチン）
  ▼
[Discord Webhook]
  │ ② 専用チャンネル（#mac-control）に「play」と自動投稿
  ▼
[Mac mini (常駐Python Bot)]
  │ ③「play」という文字を検知
  ▼
[Apple Music (osascript)]
  │ ④ 指定プレイリストを再生！
```

### 登場する用語の補足
- **Webhook（ウェブフック）**: 外部のアプリ（今回はGalaxy）から、特定のURL宛にデータを送るだけでDiscordのチャンネルにメッセージを投稿できる仕組みです。（送信専用）
- **Discord Bot（ボット）**: Discordのチャンネルを見張り、特定のメッセージ（今回は「play」）が来たらプログラムを動かすロボットアカウントです。（受信用）
- **AppleScript (`osascript`)**: Mac標準の自動操作機能です。Pythonから「Apple Musicでこのプレイリストを流して」とMacに命令するために使います。

```text
my-lab/
├── docs/
│   └── music-automation.md      # 本設計書・手順書
├── projects/
│   └── music-automation/        # プログラム本体を入れるフォルダ（ステップ2以降で作成）
│       ├── bot.py               # Discordを監視して音楽を再生するPythonスクリプト
│       ├── requirements.txt     # 必要なライブラリ一覧（discord.pyなど）
│       └── .env                 # Botのトークン（秘密の鍵）を保存するファイル（※Git管理外）
└── ai-context/
    └── handoff-log.md           # 作業の進捗・引き継ぎ記録
```

> **重要（セキュリティ）**: Discord Botの「トークン（パスワードのようなもの）」や「Webhook URL」は、GitHubに公開されると悪用される危険があるため、コードに直接書かず `.env` という隠しファイルに保存し、`.gitignore`（Gitに記録しないリスト）に登録して管理します。

## 4. 【Step 1】DiscordのチャンネルとBotの準備手順

まずは中継場所となるDiscordの設定を行います。PC（Mac mini）のブラウザまたはDiscordアプリで進めるとスムーズです。

### 4-1. 自分専用のサーバーとチャンネルを作る
1. Discordアプリを開き、左側のサーバー一覧の一番下にある **「＋（サーバーを追加）」** をクリック。
2. **「オリジナルの作成」** ＞ **「自分と友達のため」** を選び、適当な名前（例：`My Lab` や `自宅システム`）をつけて作成。
3. テキストチャンネルの横にある「＋」を押し、**`mac-control`** という名前のチャンネルを作成します。

### 4-2. Webhook（Galaxyからの送信窓口）を作る
1. 作成した `#mac-control` チャンネルの横にある **「⚙️（チャンネルの編集）」** をクリック。
2. 左メニューの **「連携サービス」** ＞ **「ウェブフックを作成」** をクリック。
3. 名前は何でもOKです（例：`Galaxy Alarm`）。
4. **「ウェブフックURLをコピー」** を押して、メモ帳などに控えておきます（後でGalaxyの設定に使います）。

### 4-3. Discord Bot（Mac miniの受信担当）を作る
次に、チャンネルのメッセージを読み取るためのBotを作成します。

1. ブラウザで **[Discord Developer Portal](https://discord.com/developers/applications)** にアクセスし、自分のDiscordアカウントでログインします。
2. 右上の **「New Application」**（青いボタン）をクリック。
3. 名前（例：`MacMusicBot`）を入力し、利用規約にチェックを入れて **「Create」** を押します。

#### ① Botのトークン（秘密の鍵）を発行する
1. 左側メニューの **「Bot」** をクリック。
2. **「Reset Token」** というボタンを押し、確認画面で「Yes, do it!」を押します（パスワードや2段階認証を求められたら入力します）。
3. 表示された長い文字列（トークン）の下にある **「Copy」** を押して、**メモ帳などに大切に控えておいてください**。（※この画面を閉じると二度と表示されません。忘れたらもう一度Reset Tokenを押せばOKです）

#### ② メッセージを読み取る権限（超重要！）をONにする
同じ「Bot」設定画面のまま、少し下にスクロールします。
1. **「Privileged Gateway Intents」** という項目を探します。
2. その中にある **「MESSAGE CONTENT INTENT」** のスイッチを **ON（緑または青）** にします。
   - ※補足：これをONにしないと、Botが「メッセージが来たこと」は分かっても「中身が『play』かどうか」を読めません。
3. 画面下に表示される **「Save Changes」**（緑のボタン）を必ず押して保存します。

#### ③ Botを自分のサーバーに招待する
1. 左側メニューの **「OAuth2」** をクリック。
2. 下にスクロールして **「OAuth2 URL Generator」**（Scopes）の枠の中から、**`bot`** にチェックを入れます。
3. さらにその下に **「Bot Permissions」**（Botの権限）という枠が出てくるので、以下の2つにチェックを入れます。
   - `View Channels`（チャンネルを見る）
   - `Read Message History`（メッセージ履歴を読む）
4. 一番下に **「Generated URL」** が作られるので、**「Copy」** を押します。
5. コピーしたURLをブラウザの新しいタブに貼り付けて開きます。
6. 「サーバーに追加」の画面が出るので、先ほど作った自分のサーバーを選び、**「はい」** ＞ **「認証」** を押します。

これで `#mac-control` チャンネルにBotが入室したら準備完了です！
