## ✨ v1.0.0 の主な機能

1. **秒単位のリアルタイム・カウントダウン（省電力設計）**
   - Android 標準の `Chronometer` コンポーネントを使用しているため、バックグラウンドでバッテリーを消費せずにホーム画面上で「**12:34**」のように1秒ずつカウントダウンが進みます。
   - バスが発車した瞬間に自動で「次の便」へ表示が切り替わります。
2. **往復ワンタップ切替（デフォルト：JR発 ➔ GNFJ）**
   - **JR発 ➔ GNFJ（会社行）** ⇄ **GNFJ発 ➔ 駅（帰り）** をウィジェット右上の `⇄ 切替` ボタンで即座に往復切り替えできます。
   - 便番号（`1-1` 等）を省き、2×2サイズでも「次発」「次々発」「3本目」の発着時刻が途切れず表示されます。
3. **アプリ内の全体時刻表（5列テーブル）**
   - ウィジェットをタップして開くアプリ画面にて、元の時刻表と同じ5列（`GNFJ発 | 京急(降) | JR発 | 京急(乗) | GNFJ着`）の全25便を一覧でき、次発便がハイライト表示されます。
4. **Galaxy「Home Up（Good Lock）」対応**
   - 最小 `1×1` マス（40dp）からの縦横自由リサイズおよび DIY Home に対応しています。

## 📌 次回アップデート（v1.1.0）に向けた改善課題（バックログ）

次回開発再開時は、以下の3点を優先して改善します：

1. **ウィジェット内のフォント拡大（余白の有効活用）**
   - **現状の課題:** 2×2ウィジェット内の余白にまだ余裕があるため、文字をもう少し大きくできる。
   - **次回対策:** パディングと余白を詰め、「次発の発車時刻」「カウントダウン数字」「次々発・3本目の発着時刻」のフォントサイズを一回り大きくして視認性を高める。
2. **アプリを開いたときの時刻表の一覧性改善（縦長解消＆カウントダウン縮小）**
   - **現状の課題:** アプリ（`MainActivity`）上部のカウントダウンカードが大きすぎることもあり、全体時刻表が縦に長くなりすぎて一画面で見づらい。
   - **次回対策:** アプリ上部のカウントダウン表示をスリムな1〜2行バーに縮小（または折りたたみ）し、時刻表の各行の高さ（上下パディング）もコンパクトに詰めて、スクロールしなくても一目で全体が見渡せるレイアウトにする。
3. **Galaxy「モードとルーチン」からの往復自動切替対応**
   - **現状の課題:** 毎日の通勤・退勤で手動タップしなくても、Galaxy の「モードとルーチン」（時間帯・場所・アラーム連動など）から往路／復路を切り替えられると便利。
   - **次回対策:** ルーチンの「アプリアクション（またはショートカット／インテント実行）」から直接呼び出せる **「往路（JR発➔会社）にセット」「復路（会社発➔駅）にセット」「往復トグル切替」用の透明アクティビティ（App Shortcuts / Activity Alias）** を追加する。これにより、Galaxy のルーチンで「朝は自動でJR発、夕方・会社到着後は自動でGNFJ発」に完全自動化できるようにする。
