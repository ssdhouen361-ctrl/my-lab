# 🚌 社バス カウントダウンウィジェット (`company-bus-widget`)

Yahoo!乗換案内のカウントダウンウィジェットをイメージした、**GNFJ 社バス専用の Android ホーム画面ウィジェット（Galaxy Home Up 対応）** です。

---

## ✨ 主な機能

1. **秒単位のリアルタイム・カウントダウン（省電力設計）**
   - Android 標準の `Chronometer` コンポーネントを使用しているため、バックグラウンドでバッテリーを消費せずにホーム画面上で「**あと 12:34**」のように1秒ずつカウントダウンが進みます。
   - バスが発車した瞬間に自動で「次の便」へ表示が切り替わります。
2. **3つのルートをワンタップ切替（デフォルト：JR発 ➔ GNFJ）**
   - **🚌 JR発 ➔ GNFJ（会社行）**【初期設定】
   - **🚌 GNFJ発 ➔ JR・京急（帰り）**（※13:50便・17:10便の「⚠️京急のみ(JR通過)」も自動表示）
   - **🚌 京急発 ➔ GNFJ（会社行）**
   - ウィジェット右上の `⇄ 切替` ボタン、またはアプリ本体画面からいつでも切り替えられます。
3. **Galaxy「Home Up（Good Lock）」完全対応**
   - 最小 `1×1` マス（40dp）からの縦横自由リサイズおよび DIY Home（自由拡大縮小）に対応しています。
   - ウィジェットの高さに合わせて、「次発のみ」「次発＋次々発」「3本目までフル表示」が自動で切り替わり、文字が見切れない設計になっています。

---

## 📲 Galaxy S26 Ultra へのインストール手順（コピペ・タップだけ）

このプロジェクトは GitHub に保存されると、GitHub Actions（クラウド自動ビルド）が自動で `.apk` ファイルを作成します。

1. Galaxy S26 Ultra で以下の GitHub リリースページを開きます（ビルド完了までプッシュ後 約2〜3分）：
   - **リリースページ:** `https://github.com/ssdhouen361-ctrl/my-lab/releases/tag/bus-widget-latest`
   - （または Actions ページ `https://github.com/ssdhouen361-ctrl/my-lab/actions` の最新実行結果）
2. **`company-bus-widget.apk`** をタップしてダウンロードし、開いてインストールします。
   - ※初回のみ「提供元不明のアプリ」の許可を求められた場合は「許可」をオンにします。
   - ※Google Play プロテクトの確認が出た場合は「詳細」➔「インストールする（安全でない場合でも）」を選択してください（個人作成アプリのため表示されます）。
3. ホーム画面の空いている場所を長押し ➔ **「ウィジェット」** ➔ **「社バス案内 (GNFJ)」** を選んでホーム画面に配置します！
