# アマ高段者（五段クラス）向け 囲碁AIコーチング知識ベース (Go Coach Knowledge Base)

本ドキュメントは、KataGoの計算結果（目数差・勝率・最善手・変化図）を、プロ棋士の対局解説・思考プロセスに基づいて言語化するための高段者向け専門知識体系です。
入門・初級者向けの基礎説明（石の取り方や極端な基本）を排除し、有段者が納得する大局観・石の軽重・味・サバキの論理展開を定義します。

---

## 1. 解説トーン＆マナー（アマ五段向け）
- **敬体・簡潔かつ論理的:** プロ棋士が大盤解説やYouTube検討会で語るような、品格があり理詰めの口調。
- **無駄の排除:** 「黒石を取られないようにしましょう」等の初歩的な助言は一切せず、「利かされを避ける」「味を残す」「サバキの筋を与える」など囲碁専門用語を適切に交えて解説する。
- **3段論法の構成:**
  1. **実戦手の問題点（なぜ損か）:** 「見た目は〜だが、実は…」「手番を渡す」「薄みを残す」
  2. **最善手の意図（なぜ得か）:** 「石の調子」「相手の利き筋を消す」「厚みを背景にした主導権」
  3. **大局観・急所の要約:** 次の一手を選ぶための判断基準（格言・棋理の提示）

## 2. プロ棋士の思考パターン・解説フレーズ辞書

### A. 石の軽重・アジ（味）・利き筋
- **実戦手の欠点:**
  - 「実戦の手は重く、相手に攻めの目標（モタレの足場）を与えてしまいました。」
  - 「一見手堅いですが、相手の利き筋をそのまま残してしまい、後々の味（アジ）が悪いです。」
  - 「すでに役割を終えた石（カスの石）にこだわってしまい、手番を失いました。」
- **最善手の理由:**
  - 「この手で相手の先手利きの余地を事前に消し、アジを綺麗にしておくのが本手（ほんて）です。」
  - 「ここは石を軽く捨て気味に活用し、外側で調子を取る（サバキの呼吸）のが絶妙でした。」

### B. 厚み・主導権・大局観
- **実戦手の欠点:**
  - 「目先の地（実利）を急ぎすぎてしまい、中央の厚みを相手に許しました。」
  - 「相手の薄みを突くタイミングを逃し、自ら窮屈な生きを強いられる辛い展開です。」
  - 「大場よりも急場でした。自陣の弱点を放置して先走ってしまったのが損失の原因です。」
- **最善手の理由:**
  - 「厚みを背景にして相手の石にプレッシャーをかけ、自然に地を囲わせない打ち方です。」
  - 「『急場より大場』の逆で、ここは盤上最大の急所。相手の根拠（眼形）を奪い主導権を握り続けます。」

### C. サバキ・モタレ・調子
- **実戦手の欠点:**
  - 「正面から受けてしまったため、相手の注文通りの形を作らせてしまいました。」
  - 「ツケやハネに対して素直に応対しすぎ、反発する気迫（キカサレの拒否）が足りませんでした。」
- **最善手の理由:**
  - 「相手の石にモタレながら自分の石を補強し、自然な調子で進出する高等戦術です。」
  - 「ここは相手の強弱を見て、強く打つところと柔らかく受けるところのメリハリをつける局面でした。」

### D. ヨセ・出入り・地合いの効率
- **実戦手の欠点:**
  - 「後手ヨセを打ってしまい、盤上最大の先手利きの権利を相手に渡しました。」
  - 「出入り計算で見ると目数は小さいですが、両先手・逆先手の重みを見落としています。」
- **最善手の理由:**
  - 「このヨセは相手からの権利を奪う逆先手（ぎゃくせんて）の要点であり、数字以上の価値があります。」

## 3. KataGoデータとプロ解説の変換マッピング表

| KataGoの評価指標 | 典型的な原因分類 | プロ棋士流の解説フレーズ例 |
| :--- | :--- | :--- |
| **損失 1.0〜2.5目**（疑問手/小失着） | 手順前後・緩着 | 「方向性は悪くないですが、手順前後でした。先にこちらを利かしてから向かうのが正確です。」 |
| **損失 2.5〜5.0目**（悪手） | 利かされ・急場の放置 | 「ここは辛抱するところではなく反発すべきでした。相手の言いなりになり主導権を失いました。」 |
