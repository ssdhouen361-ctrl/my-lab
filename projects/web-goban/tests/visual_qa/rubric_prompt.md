## 8 項目採点基準（各 1〜5 点の整数）

1. **`board_geometry`（盤面幾何学・石配置精度）**
   - 罫線が滲みなく明瞭で、石の中心が交点と一致しているか（ズレ 2px 未満）、盤面が正方形比を保っているか。
2. **`coordinates_margin`（座標ラベル＆安全余白）**
   - `A-T`（`I` 除外）と `1-19`（9 路は `A-J` / `1-9`）が見切れず、左右 16px 安全余白・上下セーフエリア内に美しく収まっているか。
3. **`candidate_readability_cud`（候補手マーカー可読性・CUD 配慮）**
   - 青二重リング・深緑太枠・アンバー小円など色＋形状の二重表現が判別でき、数字が文字潰れしていないか（該当しない画面では盤面・要素視認性で評価）。
4. **`ghost_reticle_pv`（ゴースト石・十字ガイド・PV 番号識別性）**
   - 仮置きゴースト石・十字照準・半透明 PV 石と番号が確定石と明確に区別できるか（該当しない画面では 4 以上を基準に破綻有無を評価）。
5. **`layout_alignment`（バー・シート・右パネル余白整列）**
   - 要素の重なり・画面端はみ出し・不自然な折り返し・盤面位置のズレがなく整列しているか。
6. **`japanese_text_contrast`（日本語テキスト品質＆コントラスト）**
   - 日本語文字化け・不自然な改行・暗色背景での低コントラスト（読めない文字）がないか。
7. **`graph_heatmap_badges`（グラフ・ヒートマップ・バッジ視認性）**
   - SVG 勝率グラフ、悪手バッジ、地合いヒートマップ、死活 `×` マーク、Lv3 ヒント枠が混濁せず読み取れるか。
8. **`dark_theme_aesthetics`（ダークテーマ統一感・審美性）**
   - 全体が `#1A1D21` 基調の落ち着いたダークトーンと木目盤面で統一され、白飛びや未スタイル要素がないか。

## 判定ルール（PASS / WARN / FAIL）

- **`PASS`**: 全 8 項目が 4 点以上、かつ致命的・中程度の視覚欠陥がない。
- **`WARN`**: 3 点の項目があるが操作・閲覧に支障はなく、軽微な磨き込み余地のみ。
- **`FAIL`**: いずれかの項目が 2 点以下、または以下の致命的欠陥が 1 つでも存在する：
  - 盤面真っ白／未描画／大きく歪んだアスペクト比
  - 石と罫線の明らかな位置ズレ
  - UI ボタン・テキストの重なり、画面外見切れ、文字潰れで判読不能
  - 日本語の文字化け、コントラスト不足で読めない状態
  - 該当画面で表示されるべき主要要素（例：ゴースト石、PV、シート、グラフ、解説、ヒートマップ）が欠落

## 出力要件

- 指定された JSON Schema に厳密準拠した **純粋な JSON オブジェクトのみ** を出力してください。
- `images` 配列には上記 10 ファイルすべてを順番どおり含めてください。
- `fail_count` は `images` 内で `status == "FAIL"` の件数と厳密に一致させ、`fail_count > 0` の場合 `overall_status` は必ず `"FAIL"` にしてください。
- 問題点（`issues`）および修正提案（`fix_suggestion`）は日本語で具体的に記述してください。
